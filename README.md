# Push It To The Limit

This was a project meant for my biker group @pushittothelimit (follow us on insta!)

It has a members list, a chat and a page where you can plan a next meeting or rideout and invite everyone. People could respond whether they are coming or not. 

This project was started before whatsapp released a bunch of new features that basically made this app useless since we could plan events there now. And surprise - a one woman app cannot compete with whatsapp :open_mouth: :joy: so I did not finish this project but I have learned a lot about flutter and server communication so I still view it as a win :muscle:
